# Library-management-readme
A simple C++ Library Management System that allows users to add, search, display, issue, and return books. Developed using Object-Oriented Programming (OOP) concepts with a menu-driven interface.
📚 Library Management System (C++)

A simple, menu-driven Library Management System developed in C++ using Object-Oriented Programming (OOP). This project allows users to manage library books efficiently by adding, displaying, searching, issuing, and returning books.

🚀 Features

- ➕ Add Books: Add new books with unique IDs, titles, and author names.
- 📖 Display Books: View all books available in the library system.
- 🔍 Search Books: Search for books using their unique ID.
- 📤 Issue Books: Issue available books to library users.
- 📥 Return Books: Return previously issued books.
- 📊 Book Status: Check whether a book is available or issued.
- 🔄 Interactive Menu: Easy-to-use menu-driven interface.

🛠️ Technologies Used

- Language: C++
- Concepts: Object-Oriented Programming (OOP)
- Data Structure: Vector
- Programming Concepts: Classes, Objects, Functions, Loops, Conditional Statements, and Switch Statements.
